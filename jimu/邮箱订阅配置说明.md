# 邮箱订阅功能配置说明

## 概述
本文档提供了三种不同的邮箱订阅解决方案，当用户提交邮箱后，您会收到通知。

## 方案一：EmailJS（推荐）

### 优点
- 完全免费（每月200封邮件）
- 设置简单
- 支持自定义邮件模板
- 无需后端服务器

### 配置步骤

1. **注册EmailJS账户**
   - 访问 https://www.emailjs.com/
   - 注册免费账户

2. **配置邮件服务**
   - 在EmailJS控制台添加邮件服务（Gmail、Outlook等）
   - 获取Service ID

3. **创建邮件模板**
   - 创建新模板
   - 设置收件人、主题、内容
   - 获取Template ID

4. **获取用户ID**
   - 在EmailJS控制台获取Public Key

5. **更新代码**
   ```javascript
   // 在 assets/js/email-subscription.js 中替换以下值：
   emailjs.init("YOUR_USER_ID"); // 替换为您的Public Key
   
   emailjs.send("YOUR_SERVICE_ID", "YOUR_TEMPLATE_ID", {
       to_email: "lzk99018@gmail.com", // 您的邮箱
       from_email: email,
       subject: "新的邮箱订阅",
       message: `有新的用户订阅了您的网站：${email}`
   })
   ```

6. **在HTML中引入**
   ```html
   <!-- 在所有页面的</body>标签前添加 -->
   <script src="https://cdn.jsdelivr.net/npm/@emailjs/browser@3/dist/email.min.js"></script>
   <script src="assets/js/email-subscription.js"></script>
   ```

## 方案二：Google Forms

### 优点
- 完全免费
- 自动发送邮件通知
- 数据存储在Google Sheets中

### 配置步骤

1. **创建Google Forms**
   - 访问 https://forms.google.com/
   - 创建新表单
   - 添加邮箱字段

2. **设置邮件通知**
   - 在表单设置中启用邮件通知
   - 添加您的邮箱地址

3. **获取表单URL**
   - 发布表单
   - 复制表单URL

4. **更新代码**
   ```javascript
   // 在 assets/js/google-forms-subscription.js 中替换：
   const googleFormUrl = 'YOUR_GOOGLE_FORM_URL'; // 您的表单URL
   formData.append('entry.123456789', email); // 替换为实际字段ID
   ```

5. **在HTML中引入**
   ```html
   <script src="assets/js/google-forms-subscription.js"></script>
   ```

## 方案三：Webhook

### 优点
- 高度可定制
- 可以连接到各种服务
- 支持复杂的数据处理

### 配置步骤

1. **选择Webhook服务**
   - **Slack**: 发送到Slack频道
   - **Discord**: 发送到Discord频道
   - **Zapier**: 连接到各种应用
   - **自定义API**: 自己的后端服务

2. **Slack配置示例**
   - 创建Slack应用
   - 获取Webhook URL
   - 更新代码中的URL

3. **更新代码**
   ```javascript
   // 在 assets/js/webhook-subscription.js 中替换：
   fetch('YOUR_WEBHOOK_URL', {
       method: 'POST',
       headers: {
           'Content-Type': 'application/json',
       },
       body: JSON.stringify(data)
   })
   ```

4. **在HTML中引入**
   ```html
   <script src="assets/js/webhook-subscription.js"></script>
   ```

## 故障排除

### 常见问题

1. **EmailJS发送失败**
   - 检查Service ID和Template ID是否正确
   - 确认邮件服务配置正确

2. **Google Forms不工作**
   - 检查表单URL是否正确
   - 确认字段ID是否正确

3. **Webhook无响应**
   - 检查Webhook URL是否有效
   - 确认服务端配置正确

### 调试方法

1. 打开浏览器开发者工具
2. 查看Console标签页的错误信息
3. 检查Network标签页的网络请求
